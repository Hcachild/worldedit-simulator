# 用voronoi的办法来做等宽的辐条

## 动态内容

用voronoi的办法来做等宽的辐条

//g 251 -c 
n=12
d=5
t=2*pi/n;
for(i=0;i<n*3;i+=3){
megabuf(i,cos(t*i/3))
megabuf(i+2,-sin(t*i/3))
}
A=closest(x+d,y,z,0,n,3)
B=closest(x-d,y,z,0,n,3)
C=closest(x,y,z+d,0,n,3)
D=closest(x,y,z-d,0,n,3);
if(A!=B||B!=C||C!=D)1

先生成多边形的顶点，然后生成voronoi图的边缘 
n：数量，d：宽度/2
加-c为了更精准控制d，去掉没影响，把d改小就行
