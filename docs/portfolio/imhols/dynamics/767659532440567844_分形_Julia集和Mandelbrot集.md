## 动态内容

分形——Julia集和Mandelbrot集 

图前5为Julia集，6为Mandelbrot集合

Julia ：
//generate 251 x*=2;z*=2;a=x;b=z;cr=0.8;ci=0;for(n=1,20){na=a^2-b^2+cr;nb=2*a*b+ci;a=na;b=nb}sqrt(a^2+b^2)<2 

z=(a,b)为复平面内点的坐标(x,z)，cr为c的实部，ci为c的虚部，改变二者的值获得不同的形状，for循环从1迭代到20，迭代过程为z=z^2+c，循环结束判断迭代后的a和b是否收敛即模小于2，小于就在此处的x,z生成方块

Mandelbrot :
//generate 251 x*=2;z*=2;a=0;b=0;cr=x;ci=z;for(n=1,20){na=a^2-b^2+cr;nb=2*a*b+ci;a=na;b=nb}sqrt(a^2+b^2)<2 

z=(0,0)为初始值，cr和ci为复平面平面内点的坐标(x,z)
