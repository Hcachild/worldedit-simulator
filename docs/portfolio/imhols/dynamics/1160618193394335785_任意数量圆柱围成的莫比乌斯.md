# 任意数量圆柱围成的莫比乌斯

> 作者：**imhols**（UID 632698683） · 1月22日 · 类型：`DYNAMIC_TYPE_DRAW` · [原动态](https://www.bilibili.com/opus/1160618193394335785)

**WorldEdit / 程序化建模相关**

## 动态内容

//g 251 n=8;R=0.3;a=2;r=R/(1+1/sin(pi/n));d=0;X=sqrt(x^2+z^2)-(1-R);rotate(X,y,a*atan2(x,z))for(i=1,n){if(sqrt((X-(R-r))^2+y^2)<r){data=d;return 1}rotate(X,y,2*pi/n);d+=1}0 
n：小圆数量(颜色数量最多16)，R；小圆围成的小圆的半径(0到0.5)a：旋转程度
